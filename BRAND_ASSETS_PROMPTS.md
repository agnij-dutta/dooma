# DOOMA — AI image prompts (logo + cover)

Brand: **DOOMA — "Night Court"**, a public AI courtroom on 0G. Tagline *Settle it on-chain.* Maxim **SINE FAVORE** ("the judge owes no one"). Aesthetic = a crypto-native judicial tribunal: warm near-black ink, brass/judicial gold, oxblood/burgundy leather, parchment, editorial serif gravitas, wax-seal + rubber-stamp motifs, courtroom spotlight, film grain. Ceremonial, dramatic, premium — never generic web3.

**Palette (give these hexes to the tool):** ink `#0B0B0D` · brass gold `#C9A24D` / bright `#E2BF69` · oxblood `#A83A40` · burgundy leather `#3A1A1E` · parchment `#E8E0CD`.

> Tip: AI tools mangle text. For the LOGO, prefer generating the **emblem/mark only**, then set the word "DOOMA" yourself in **Instrument Serif**. Prompts below include both an emblem-only version (recommended) and a full-lockup attempt.

```
A logo lockup for "DOOMA": an engraved brass-gold scales-of-justice emblem above
```

**Negative / avoid:** neon, cyberpunk glow, purple/blue gradients, 3D cartoon, busy backgrounds, stock "AI brain" clichés, watermark, misspelled text, more than one emblem.

**Tool notes:**
- *Midjourney:* keep the `--style raw --ar` flags; add `--no text` for 1a; try `--stylize 250`.
- *GPT-image / DALL·E / Ideogram (best for text):* drop the `--flags`, paste the prose. **Ideogram** handles the wordmark (1c) most reliably.
- Ask for a **transparent PNG** and a **monochrome (all-gold and all-parchment) version** for use on light/dark.

### Consistency checklist (so logo + covers feel like one brand)
- Same palette hexes every time. Brass-gold is the ONLY accent — no second bright color.
- One light source: a single overhead spotlight. Everything else falls into warm shadow.
- Recurring motifs: scales ⚖, gavel, wax seal, engraved hairline rules. Pick one per asset; don't crowd.
- Texture always: subtle film grain + a hint of parchment/leather. Never flat pure black.
- Mood words to keep pasting: *ceremonial, editorial, engraved, premium, midnight tribunal, spotlit brass.*
